Верни только компактный JSON строго по схеме и ровно с пятью верхнеуровневыми блоками.

Блок 1: фактическая сводка, выбранные конкуренты снизу/сверху, текущее позиционирование объявления, 1–3 обоснованные ЦА, отдельная гипотеза позиционирования, существенные проверки.
Блок 2: подтверждённые плюсы; отдельная реальная защита премии; риски; факторы, не защищающие цену; неявные преимущества; честный ответ на главный вопрос рационального выбора.
Блок 3: компактная сравнительная таблица только по значимым факторам и разбор угрозы снизу/сверху. price_delta: для нижнего конкурент минус цель, для верхнего конкурент минус цель.
Блок 4: buyer value отдельно по каждой ЦА, недостатки текущего позиционирования (различай упаковку и продукт/цену), рекомендуемая гипотеза, 2–4 storytelling-гипотезы.
Блок 5: вопросы к звонку и задачи просмотра, рождённые именно этим анализом.

Если нижнего или верхнего конкурента нет, object_id и price/price_delta = null, а текст честно сообщает об отсутствии представленной альтернативы. Не добавляй поля вне схемы.
