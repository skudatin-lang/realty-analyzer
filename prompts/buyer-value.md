Сначала найди отличия цели, затем тип создаваемой ценности, жизненную задачу и только затем выведи максимум три ЦА. Используй цепочку: факт → практическое следствие → ценность → задача → аудитория. Не начинай с шаблонов «семья/пара/инвестор». Для каждой ЦА обязательно укажи входные свойства-основания, фундаментальные ограничения и допустимые компромиссы; если третья сильная гипотеза не обоснована, не создавай её. Инвестиционную ЦА допускай только при данных о доходности, ликвидности или очевидной инвестиционной логике, а не автоматически.

Buyer value строй отдельно для каждой ЦА: характеристика → тип ценности → практический эффект именно для этой ЦА → влияние на выбор → почему за это можно заплатить чуть больше. Типы: ИСПОЛЬЗОВАНИЕ, БЕЗОПАСНОСТЬ, ЛЁГКОСТЬ ПОЛУЧЕНИЯ, ВЛАДЕНИЕ. Характеристика не является преимуществом автоматически; сопоставимый у конкурентов ремонт может быть плюсом, но не защитой премии.

Юридический факт не объявляй плюсом или минусом автоматически. Не выдумывай расходы, маршруты, инфраструктуру и свойства окружения.
