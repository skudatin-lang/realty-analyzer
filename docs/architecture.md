# Архитектура

Браузер хранит File/Blob только в памяти. Каждый объект отправляется отдельным multipart-запросом в функцию. После extraction frontend отзывает Object URL и удаляет файлы. Детерминированные расчёты выполняются локально. Итоговый endpoint видит только компактный JSON.

Cloud Function получает секрет через Lockbox, вызывает ProxyAPI/OpenRouter и валидирует оба AI-ответа JSON Schema. Внешняя БД и файловое хранилище не используются. Отчёт текущей сессии передаётся между страницами через sessionStorage без изображений. Service Worker работает только с app shell.
